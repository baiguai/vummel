Key Bindings

a = Add a new node.
= = Duplicate current node.
r = Rename node (change its type).
u = Add a new link node.
c = Start connection (select the second node and hit Enter).
X = Disconnects two nodes in the same manner as connecting them.
D = Delete the selected node.
i = Select current node's text field.
1-9 = How many times to repeat certain actions.
h = Move selected node left.
H = Reduce width of selected node.
j = Move selected node down.
J = Increase selected node's height.
k = Move selected node up.
K = Reduce selected node's height.
l = Move selected node right.
L = Increase selected node's width.
< = Move selected node left half step.
> = Move selected node right half step (if connecting create arrow).
^ = Move selected node up half step.
- = Move selected node down half step.
' = Show history.
M = Enter select multiple nodes mode (Escape exits).
q = Show mini-map.
! = Set auto-saver port (4000-4999, or 0 to disable).
Enter = When a node is on top of another, moves it into that node.
d = Detaches a child node from its parent.
z = Increase selected node's text area.
Z = Decrease selected node's text area.
w = Cycles through the nodes.
s = Save the current diagram.
S = Save as (enter new file name).
n = Save via nodejs (requires auto-saver port).
U = Upgrade from another Vummel diagram file.
G = Scroll to the top left.
, = Zoom out.
. = Zoom in.
] = Scroll half screen right.
[ = Scroll half screen left.
} = Scroll half screen down.
{ = Scroll half screen up.
0 = Reset zoom.
p = Start snap (select second node hit Enter).
# = Sets a custom color for the node. OR manages color 'palettes'.
@ = Reset a node's color to the theme's default.
% = Select a theme from the built-in themes list.
/ = Search and select a node. (begin with "#" to search by palette).
`<`> = Show a list of current marks.
m<letter> = Set mark (A-Z, a-z).
`<letter> = Go to mark (A-Z, a-z).
m- = Remove mark.
Escape = Deselect current note's text, or deselect current node.
